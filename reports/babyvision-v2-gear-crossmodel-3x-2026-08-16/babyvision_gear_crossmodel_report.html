Abstract

BabyVision-v2 compared Qwen 3.7 Plus, Claude Opus 5, and Claude Fable 5 on 33 public base gear-assembly questions under one frozen six-view image-only condition. Each model contributed three one-attempt replicates. Claude Opus 5 achieved the highest strict accuracy at 63/99 (63.6%; question-cluster 95% CI 47.5-78.8%). Operational failures remain in the primary denominator. The study also quantifies repeatability, error type, response-model identity, tokens, latency, and reconstructed list-price cost. A causal MCP contrast was not run because matched raw CAD or scene assets are absent.

Limitations and next causal experiment

The public base set contains 33 questions with uneven type counts, and replicate observations remain clustered by question. The model and price records describe services observed on August 16, 2026. Most importantly, the dataset has no provenance-matched raw CAD, mesh, assembly, or scene file. A valid MCP study must add those assets for all 33 questions without changing prompts, scorers, model versions, deadlines, or replication.

Reproducibility

The report bundle includes the immutable plan, runtime lock, task and scoring hashes, Docker image digests, model probes, run state, all aggregate tables, the complete incorrect audit, and a QA receipt. A prose-equivalent Markdown manuscript is available at babyvision_gear_crossmodel_report.md.
